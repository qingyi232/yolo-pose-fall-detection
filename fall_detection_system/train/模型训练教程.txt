================================================================================
                    YOLOv8 摔倒检测模型训练教程
                        （小白保姆级教程）
================================================================================

【前言】
这个教程会手把手教你如何训练自己的摔倒检测模型。
即使你完全不懂代码，只要按照步骤一步一步来，也能成功训练出模型。
整个过程大约需要 1-2 小时（取决于你的电脑配置）。

================================================================================
                            第一部分：准备工作
================================================================================

【1.1 检查你的电脑配置】

训练模型需要一定的电脑配置，请先检查：

✓ 必须有：
  - Windows 10 或 Windows 11 系统
  - 至少 8GB 内存
  - 至少 10GB 硬盘空间

✓ 强烈建议有：
  - NVIDIA 显卡（GTX 1050 以上）
  - 如果没有显卡，训练会非常慢（可能需要几天）

【如何查看自己有没有 NVIDIA 显卡？】
1. 右键点击桌面空白处
2. 如果看到 "NVIDIA 控制面板" 选项，说明你有 NVIDIA 显卡
3. 或者按 Win+R，输入 dxdiag，回车，点击"显示"选项卡查看

--------------------------------------------------------------------------------

【1.2 确保 Python 已安装】

如果你之前已经能运行摔倒检测系统，说明 Python 已经安装好了，跳过这步。

如果没有安装 Python：
1. 打开浏览器，访问 https://www.python.org/downloads/
2. 点击黄色的 "Download Python 3.x.x" 按钮
3. 运行下载的安装程序
4. 【重要！】勾选 "Add Python to PATH"
5. 点击 "Install Now"

--------------------------------------------------------------------------------

【1.3 安装训练所需的额外依赖】

打开命令提示符（按 Win+R，输入 cmd，回车），输入以下命令：

pip install pandas matplotlib -i https://pypi.tuna.tsinghua.edu.cn/simple

等待安装完成即可。

================================================================================
                            第二部分：准备数据集
================================================================================

【2.1 了解你的数据集】

你有三个数据集文件：
- fall-detection.v2i.yolov8.zip （33.72MB）- 摔倒检测专用数据集
- val2017.zip （777.80MB）- COCO验证集
- WiderPerson.zip （969.72MB）- 行人检测数据集

【建议】如果你是第一次训练，先只用 fall-detection.v2i.yolov8.zip 这个小的。
       等熟悉流程后，再尝试用全部数据集。

--------------------------------------------------------------------------------

【2.2 解压数据集】

步骤：
1. 找到你的项目文件夹，比如：
   C:\Users\你的用户名\Desktop\fall_detection_system\

2. 进入 train 文件夹，你会看到：
   fall_detection_system\
   └── train\
       ├── datasets\        ← 数据集放这里
       ├── trainer.py
       ├── train.py
       └── ...

3. 把 fall-detection.v2i.yolov8.zip 解压到 train\datasets\ 文件夹

【如何解压？】
- 右键点击 zip 文件
- 选择 "解压到当前文件夹" 或 "Extract Here"
- 如果没有这个选项，需要先安装 WinRAR 或 7-Zip

--------------------------------------------------------------------------------

【2.3 检查数据集结构】

解压后，你的文件夹结构应该类似这样：

fall_detection_system\
└── train\
    └── datasets\
        └── fall-detection.v2i.yolov8\    ← 解压出来的文件夹
            ├── data.yaml                  ← 数据集配置文件
            ├── train\
            │   ├── images\               ← 训练图片
            │   └── labels\               ← 训练标注
            └── valid\
                ├── images\               ← 验证图片
                └── labels\               ← 验证标注

【重要】确保能看到 images 和 labels 文件夹，里面有图片和 txt 文件。

================================================================================
                            第三部分：配置数据集
================================================================================

【3.1 修改数据集配置文件】

1. 用记事本打开 train\datasets\dataset.yaml 文件

2. 把内容修改成：

# 数据集配置
path: ./datasets/fall-detection.v2i.yolov8
train: train/images
val: valid/images
nc: 2
names:
  0: person
  1: fall

3. 保存文件（Ctrl+S）

【注意】
- path 后面的路径要和你解压的文件夹名称一致
- 如果你的文件夹名称不同，请相应修改

--------------------------------------------------------------------------------

【3.2 如果使用 Roboflow 导出的数据集】

如果你的数据集是从 Roboflow 导出的（文件名包含 .v2i.yolov8），
解压后里面通常已经有一个 data.yaml 文件。

你可以直接用那个文件，只需要修改 train\train.py 中的路径：

找到这一行：
'data_yaml': 'datasets/dataset.yaml',

改成：
'data_yaml': 'datasets/fall-detection.v2i.yolov8/data.yaml',

================================================================================
                            第四部分：开始训练
================================================================================

【4.1 方法一：双击批处理文件（推荐）】

1. 在项目根目录找到 "开始训练.bat" 文件
2. 双击运行
3. 按任意键开始训练
4. 等待训练完成

--------------------------------------------------------------------------------

【4.2 方法二：命令行运行】

1. 打开命令提示符（Win+R，输入 cmd，回车）

2. 进入项目目录：
   cd C:\Users\你的用户名\Desktop\fall_detection_system\train

3. 运行训练脚本：
   python train.py

4. 按 Enter 确认开始训练

--------------------------------------------------------------------------------

【4.3 训练过程中你会看到什么】

训练开始后，屏幕上会显示类似这样的信息：

============================================================
  YOLOv8 摔倒检测模型训练
============================================================

GPU 检查
============================================================
✓ CUDA 可用
  GPU: NVIDIA GeForce GTX 1650
  显存: 4.0 GB
============================================================

训练配置:
  model: yolov8n-pose.pt
  epochs: 100
  batch_size: 8
  ...

按 Enter 开始训练...

然后会显示训练进度：

Epoch 1/100:  10%|████      | 10/100 [00:30<04:30, 0.33it/s]
  box_loss: 0.0456
  cls_loss: 0.0234
  ...

【这些数字是什么意思？】
- Epoch: 当前训练轮数 / 总轮数
- box_loss: 边界框损失（越小越好）
- cls_loss: 分类损失（越小越好）
- 进度条: 当前轮次的完成百分比

--------------------------------------------------------------------------------

【4.4 训练需要多长时间？】

根据你的电脑配置和数据集大小：

| 显卡          | 小数据集(500张) | 大数据集(2万张) |
|---------------|-----------------|-----------------|
| RTX 3060      | 30-40 分钟      | 4-6 小时        |
| GTX 1650      | 1-2 小时        | 10-15 小时      |
| 无显卡(CPU)   | 10+ 小时        | 不建议          |

【建议】
- 如果用 GTX 1650，建议晚上睡觉前开始训练，第二天早上就好了
- 训练过程中不要关闭命令行窗口
- 可以正常使用电脑做其他事情，但不要运行大型游戏

================================================================================
                            第五部分：训练完成后
================================================================================

【5.1 找到训练好的模型】

训练完成后，模型文件保存在：

fall_detection_system\
└── train\
    └── runs\
        └── train\
            └── 20240105_120000\        ← 日期时间命名的文件夹
                └── weights\
                    ├── best.pt         ← 最佳模型【用这个】
                    └── last.pt         ← 最后一轮的模型

--------------------------------------------------------------------------------

【5.2 使用训练好的模型】

1. 找到 best.pt 文件

2. 复制 best.pt 到项目根目录：
   fall_detection_system\best.pt

3. 把 best.pt 重命名为 yolov8n-pose.pt
   （会提示是否替换，选择"是"）

4. 现在运行摔倒检测系统，就会使用你训练的模型了！

--------------------------------------------------------------------------------

【5.3 查看训练结果】

训练完成后，在同一个文件夹里还有：

- results.csv          ← 训练数据（可以用 Excel 打开）
- training_curves.png  ← 训练曲线图（双击打开查看）
- confusion_matrix.png ← 混淆矩阵图

这些图表可以用来分析训练效果，写论文时可以用到。

================================================================================
                            第六部分：常见问题
================================================================================

【Q1: 提示 "CUDA out of memory" 怎么办？】

这是显存不足的意思。解决方法：

1. 打开 train\train.py 文件
2. 找到这两行：
   'batch_size': 8,
   'img_size': 640,
3. 改成：
   'batch_size': 2,
   'img_size': 320,
4. 保存后重新运行

--------------------------------------------------------------------------------

【Q2: 提示 "No module named xxx" 怎么办？】

缺少依赖包。打开命令提示符，运行：

pip install xxx -i https://pypi.tuna.tsinghua.edu.cn/simple

把 xxx 替换成提示缺少的包名。

--------------------------------------------------------------------------------

【Q3: 训练到一半电脑死机/断电了怎么办？】

不用担心，训练过程中每 10 轮会自动保存一次。

1. 找到 runs\train\xxx\weights\last.pt
2. 把 last.pt 复制到 train 文件夹
3. 修改 train.py 中的 model 参数：
   'model': 'last.pt',
4. 重新运行，会从上次中断的地方继续

--------------------------------------------------------------------------------

【Q4: 训练效果不好怎么办？】

可以尝试：
1. 增加训练轮数（epochs 改成 200 或 300）
2. 使用更大的模型（model 改成 'yolov8s-pose.pt'）
3. 增加数据集数量
4. 检查数据集标注是否正确

--------------------------------------------------------------------------------

【Q5: 如何同时使用多个数据集？】

1. 把所有数据集都解压到 train\datasets\ 目录
2. 运行 python prepare_dataset.py
3. 选择选项 2（合并多个数据集）
4. 按提示输入各数据集的路径
5. 脚本会自动合并所有数据集

================================================================================
                            第七部分：进阶设置
================================================================================

【7.1 调整训练参数】

打开 train\train.py，可以修改以下参数：

config = {
    'model': 'yolov8n-pose.pt',    # 基础模型
    'epochs': 100,                  # 训练轮数（越多效果越好，但越慢）
    'batch_size': 8,                # 批次大小（显存小就调小）
    'img_size': 640,                # 图片尺寸（显存小就调小）
    'device': 'cuda',               # 设备（cuda=显卡，cpu=处理器）
    'save_period': 10,              # 每多少轮保存一次
}

【参数说明】
- epochs: 建议 100-300，越多效果越好
- batch_size: GTX 1650 建议 4，RTX 3060 建议 8-16
- img_size: GTX 1650 建议 416，RTX 3060 建议 640

--------------------------------------------------------------------------------

【7.2 使用不同的基础模型】

YOLOv8 有不同大小的模型：

| 模型名称        | 大小  | 速度 | 精度 |
|-----------------|-------|------|------|
| yolov8n-pose.pt | 最小  | 最快 | 一般 |
| yolov8s-pose.pt | 小    | 快   | 较好 |
| yolov8m-pose.pt | 中等  | 中等 | 好   |
| yolov8l-pose.pt | 大    | 慢   | 很好 |

如果你的显卡性能好，可以尝试用更大的模型获得更好的效果。

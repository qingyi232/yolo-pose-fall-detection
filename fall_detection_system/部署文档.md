# 摔倒检测系统 - 部署文档

## 写给小白的安装指南

---

## 第一步：安装Python

1. 打开浏览器，访问 https://www.python.org/downloads/
2. 点击黄色的 **"Download Python 3.x.x"** 按钮下载
3. 运行下载的安装程序
4. **重要！** 勾选 ✅ **"Add Python to PATH"**（添加到环境变量）
5. 点击 "Install Now" 安装

验证安装成功：
- 按 `Win + R`，输入 `cmd`，回车
- 输入 `python --version`，回车
- 如果显示 `Python 3.x.x` 就说明安装成功

---

## 第二步：一键安装系统

1. 打开 `fall_detection_system` 文件夹
2. **双击运行** `一键安装.bat`
3. 等待安装完成（首次约5-10分钟）
4. 看到"安装完成"提示后，按任意键关闭

---

## 第三步：运行系统

### 方式一：摄像头测试（推荐先测试）
1. 双击 `摄像头测试.bat`
2. 会弹出摄像头窗口，显示实时检测画面
3. 按 `Q` 键退出，按 `F` 键全屏

### 方式二：完整系统（带Web界面）
1. 双击 `启动系统.bat`
2. 等待显示 "API服务启动" 
3. 打开浏览器，访问 http://localhost:5000
4. 按 `Ctrl + C` 停止系统

---

## 常见问题

### Q: 双击bat文件闪退？
A: 右键点击bat文件 → 选择"以管理员身份运行"

### Q: 提示"未检测到Python"？
A: 重新安装Python，确保勾选了"Add Python to PATH"

### Q: 安装依赖很慢？
A: 脚本已使用清华镜像源加速，如果还是慢，检查网络连接

### Q: 摄像头打不开？
A: 
- 检查摄像头是否被其他程序占用
- 检查摄像头权限设置
- 尝试修改 `config/config.yaml` 中的 `url: 0` 改为 `url: 1`

### Q: 检测不准确？
A: 
- 确保摄像头能看到人的上半身或全身
- 只看到头部时检测会不准确
- 光线要充足

## 配置说明

编辑 `config/config.yaml` 可以修改：

```yaml
# 关闭区域检测（左上角蓝色方块）
intrusion:
  enabled: false   # 改为false关闭

# 关闭摔倒检测
fall_detection:
  enabled: false   # 改为false关闭

# 切换摄像头
video:
  sources:
    - url: 0       # 0=默认摄像头, 1=第二个摄像头
```

## 技术支持

如有问题，请检查：
1. Python版本是否3.8以上
2. 是否以管理员身份运行
3. 摄像头是否正常工作
4. 网络是否正常（首次需要下载模型）

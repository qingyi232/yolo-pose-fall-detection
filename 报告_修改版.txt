1.1 研究背景

在养老院、校园、工业园区等公共场景中，人员摔倒与非法闯入是威胁安全的主要风险因素。传统监控系统主要依赖人工实时观察与事后回看，不仅需要投入大量人力成本，还存在响应滞后、漏报误报等问题。例如，养老院中老人摔倒后若不能及时发现，可能导致严重后果；工业园区的危险区域若缺乏有效管控，非法闯入可能引发安全事故。

随着人工智能与计算机视觉技术的快速发展，基于算法的智能监控系统逐渐成为解决方案。YOLO系列算法凭借实时性强、检测精度高的优势，在目标检测领域得到广泛应用；YOLO-pose则能够精准提取人体关键点，为姿态分析提供技术支撑。将这两项技术融合，开发集摔倒检测与区域闯入预警于一体的智能系统，能够有效解决传统监控的痛点，满足现代化安全管控的需求。

2 相关技术

2.1 YOLOv8目标检测算法

YOLO（You Only Look Once）是一种基于深度学习的端到端目标检测算法，由Joseph Redmon等人提出，具有检测速度快、精度高的特点。与传统的两阶段检测算法不同，YOLO将目标检测任务转化为单一的回归问题，通过一次神经网络推理即可完成目标的定位与分类。

YOLOv8是Ultralytics公司于2023年发布的最新版本，在检测精度与速度上进一步提升。其核心改进包括：采用新的骨干网络结构，提升特征提取能力；优化损失函数，提高小目标检测精度；支持多尺度检测与实时推理。本系统使用yolov8n.pt模型进行人体目标检测，该模型体积小、推理速度快，适合实时监控场景。

在本系统中，YOLOv8的调用方式如下：

```python
from ultralytics import YOLO

# 加载预训练模型
model = YOLO('yolov8n.pt')

# 进行目标检测，只检测人（class=0）
results = model(frame, conf=0.5, classes=[0], verbose=False)

# 获取检测结果
for result in results:
    boxes = result.boxes
    for box in boxes:
        x1, y1, x2, y2 = box.xyxy[0].cpu().numpy()
        confidence = float(box.conf[0])
```

2.2 YOLOv8-pose姿态估计技术

YOLOv8-pose是基于YOLOv8扩展的人体姿态估计技术，能够在目标检测的同时，精准提取人体17个关键点坐标。这17个关键点包括：鼻子、左眼、右眼、左耳、右耳、左肩、右肩、左肘、右肘、左腕、右腕、左髋、右髋、左膝、右膝、左踝、右踝。

人体姿态估计是摔倒检测的核心技术支撑，通过分析人体关键点的相对位置与运动轨迹，可判断人员是否处于摔倒状态。YOLOv8-pose的核心优势在于：与目标检测共享骨干网络，推理速度快；关键点检测精度高，支持复杂姿态的准确识别；支持多人体同时检测与姿态估计。

本系统使用yolov8n-pose.pt模型，调用方式如下：

```python
from ultralytics import YOLO

# 加载姿态估计模型
model = YOLO('yolov8n-pose.pt')

# 进行姿态估计
results = model(frame, conf=0.5, verbose=False)

# 获取关键点
for result in results:
    if result.keypoints is not None:
        keypoints = result.keypoints.data.cpu().numpy()
        # keypoints shape: (N, 17, 3) - N个人，17个关键点，每个点(x, y, confidence)
```

2.4 Flask Web框架

Flask是一个轻量级的Python Web框架，由Armin Ronacher开发，采用Werkzeug作为WSGI工具库，Jinja2作为模板引擎。Flask的核心特点是"微框架"，只提供Web开发的核心功能，其他功能通过扩展实现，具有灵活性强、易于扩展的优势。

本系统使用Flask构建RESTful API服务，配合Flask-SocketIO实现WebSocket实时消息推送。主要功能包括：

1. 系统控制接口：启动/停止检测系统
2. 配置管理接口：获取/更新系统配置
3. 区域管理接口：增删改查检测区域
4. 事件查询接口：查询异常事件记录
5. 视频流接口：提供MJPEG视频流
6. WebSocket推送：实时推送检测事件

Flask的基本使用方式如下：

```python
from flask import Flask, jsonify, request

app = Flask(__name__)
socketio = SocketIO(app, cors_allowed_origins="*")
```

2.6 OpenCV计算机视觉库

OpenCV（Open Source Computer Vision Library）是一个开源的计算机视觉库，提供了丰富的图像与视频处理接口。OpenCV支持图像读取、预处理、特征提取、视频流解析等功能，能够为目标检测与姿态估计提供数据预处理支持。

在本系统中，OpenCV的主要应用包括：

1. 视频流读取：通过cv2.VideoCapture读取本地摄像头或RTSP网络流
2. 图像预处理：帧的读取、尺寸调整、颜色空间转换
3. 结果可视化：绘制目标边界框、人体骨架、检测区域
4. 区域检测：使用cv2.pointPolygonTest判断点是否在多边形区域内

OpenCV的基本使用方式如下：

```python
import cv2
```

5.1 多目标检测与人体姿态估计模块实现

多目标检测与人体姿态估计模块负责调用YOLOv8和YOLOv8-pose模型，实现人体检测与17个关键点的提取。模块包含PersonDetector类和PoseEstimator类。

核心实现代码（core/detector.py）：

```python
import cv2
import numpy as np
from ultralytics import YOLO
from loguru import logger

class PersonDetector:
    """人体检测器 - 使用YOLOv8"""
    
    def __init__(self):
        self.model = YOLO('yolov8n.pt')
        self.confidence = 0.5
        logger.info("目标检测模型加载成功")
    
    def detect(self, frame):
        """
        检测画面中的人体
        返回: [(x1, y1, x2, y2, confidence), ...]
        """
        results = self.model(
            frame, 
            conf=self.confidence,
            classes=[0],  # 只检测人
            verbose=False
        )
        
        detections = []
        for result in results:
            boxes = result.boxes
            if boxes is not None:
                for box in boxes:
                    x1, y1, x2, y2 = box.xyxy[0].cpu().numpy()
                    conf = float(box.conf[0])
                    detections.append((int(x1), int(y1), int(x2), int(y2), conf))
        
        return detections


class PoseEstimator:
    """人体姿态估计器 - 使用YOLOv8-Pose"""
    
    # 17个关键点索引
    KEYPOINTS = {
        'nose': 0, 'left_eye': 1, 'right_eye': 2,
        'left_ear': 3, 'right_ear': 4, 'left_shoulder': 5,
        'right_shoulder': 6, 'left_elbow': 7, 'right_elbow': 8,
        'left_wrist': 9, 'right_wrist': 10, 'left_hip': 11,
        'right_hip': 12, 'left_knee': 13, 'right_knee': 14,
        'left_ankle': 15, 'right_ankle': 16
    }
    
    def __init__(self):
        self.model = YOLO('yolov8n-pose.pt')
        self.confidence = 0.5
        self.keypoint_conf = 0.3
        logger.info("姿态估计模型加载成功")
    
    def estimate(self, frame):
        """
        估计画面中人体的姿态
        返回: [{'bbox': (x1,y1,x2,y2), 'keypoints': np.array, 'confidence': float}, ...]
        """
        results = self.model(frame, conf=self.confidence, verbose=False)
        
        poses = []
        for result in results:
            if result.keypoints is not None:
                keypoints = result.keypoints.data.cpu().numpy()
                boxes = result.boxes
                
                for i, kpts in enumerate(keypoints):
                    if boxes is not None and i < len(boxes):
                        box = boxes[i]
                        x1, y1, x2, y2 = box.xyxy[0].cpu().numpy()
                        conf = float(box.conf[0])
                        
                        poses.append({
                            'bbox': (int(x1), int(y1), int(x2), int(y2)),
                            'keypoints': kpts,  # shape: (17, 3)
                            'confidence': conf
                        })
        
        return poses
    
    def draw_skeleton(self, frame, keypoints, color=(0, 255, 0)):
        """在画面上绘制骨架"""
        # 骨架连接关系
        skeleton = [
            (0, 1), (0, 2), (1, 3), (2, 4),  # 头部
            (5, 6), (5, 7), (7, 9), (6, 8), (8, 10),  # 上肢
            (5, 11), (6, 12), (11, 12),  # 躯干
            (11, 13), (13, 15), (12, 14), (14, 16)  # 下肢
        ]
        
        # 绘制关键点
        for i, (x, y, conf) in enumerate(keypoints):
            if conf >= self.keypoint_conf:
                cv2.circle(frame, (int(x), int(y)), 4, color, -1)
        
        # 绘制骨架线
        for i, j in skeleton:
            if keypoints[i][2] >= self.keypoint_conf and keypoints[j][2] >= self.keypoint_conf:
                pt1 = (int(keypoints[i][0]), int(keypoints[i][1]))
                pt2 = (int(keypoints[j][0]), int(keypoints[j][1]))
                cv2.line(frame, pt1, pt2, color, 2)
        
        return frame
```

5.2 视频流处理与数据采集模块实现

视频流处理与数据采集模块负责视频流的读取与帧解析，支持本地摄像头、RTSP网络流和视频文件。模块采用多线程异步采集，保证实时性。

核心实现代码（core/video_stream.py）：

```python
import cv2
import threading
import queue
import time
from loguru import logger

class VideoStream:
    """视频流处理类"""
    
    def __init__(self, source_id, source_url, name="Camera"):
        self.source_id = source_id
        self.source_url = source_url
        self.name = name
        self.cap = None
        self.frame_queue = queue.Queue(maxsize=10)
        self.running = False
        self.thread = None
        self.last_frame = None
        self.frame_count = 0
    
    def start(self):
        """启动视频流"""
        self.cap = cv2.VideoCapture(self.source_url)
        if not self.cap.isOpened():
            logger.error(f"无法打开视频源: {self.source_url}")
            return False
        
        self.running = True
        self.thread = threading.Thread(target=self._capture_loop, daemon=True)
        self.thread.start()
        logger.info(f"视频流启动成功: {self.name}")
        return True
    
    def stop(self):
        """停止视频流"""
        self.running = False
        if self.thread:
            self.thread.join(timeout=2)
        if self.cap:
            self.cap.release()
        logger.info(f"视频流已停止: {self.name}")
    
    def _capture_loop(self):
        """视频采集循环"""
        while self.running:
            ret, frame = self.cap.read()
            if not ret:
                time.sleep(0.1)
                continue
            
            self.frame_count += 1
            self.last_frame = frame
            
            # 非阻塞放入队列
            try:
                self.frame_queue.put_nowait(frame)
            except queue.Full:
                try:
                    self.frame_queue.get_nowait()
                    self.frame_queue.put_nowait(frame)
                except:
                    pass
    
    def get_frame(self):
        """获取最新帧"""
        try:
            return self.frame_queue.get(timeout=1)
        except queue.Empty:
            return self.last_frame
    
    def is_running(self):
        return self.running and self.cap is not None and self.cap.isOpened()


class VideoStreamManager:
    """视频流管理器"""
    
    def __init__(self):
        self.streams = {}
    
    def add_stream(self, source_id, source_url, name=None):
        """添加视频流"""
        stream = VideoStream(source_id, source_url, name or f"Camera_{source_id}")
        self.streams[source_id] = stream
    
    def start_all(self):
        """启动所有视频流"""
        for stream in self.streams.values():
            stream.start()
    
    def stop_all(self):
        """停止所有视频流"""
        for stream in self.streams.values():
            stream.stop()
    
    def get_stream(self, source_id):
        """获取指定视频流"""
        return self.streams.get(source_id)
```

5.3 系统配置与管理模块实现

系统配置与管理模块负责配置文件的读取、保存与动态更新。采用YAML格式配置文件，支持嵌套键访问。

核心实现代码（core/config_manager.py）：

```python
import yaml
from pathlib import Path
from loguru import logger

class ConfigManager:
    """配置管理器 - 单例模式"""
    _instance = None
    _config = None
    
    def __new__(cls):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
        return cls._instance
    
    def __init__(self):
        if self._config is None:
            self.config_path = Path(__file__).parent.parent / "config" / "config.yaml"
            self.load_config()
    
    def load_config(self):
        """加载配置文件"""
        try:
            with open(self.config_path, 'r', encoding='utf-8') as f:
                self._config = yaml.safe_load(f)
            logger.info(f"配置文件加载成功: {self.config_path}")
        except Exception as e:
            logger.error(f"配置文件加载失败: {e}")
            self._config = {}
    
    def save_config(self):
        """保存配置文件"""
        try:
            with open(self.config_path, 'w', encoding='utf-8') as f:
                yaml.dump(self._config, f, allow_unicode=True)
            logger.info("配置文件保存成功")
        except Exception as e:
            logger.error(f"配置文件保存失败: {e}")
    
    def get(self, key, default=None):
        """获取配置项，支持点号分隔的嵌套键"""
        keys = key.split('.')
        value = self._config
        for k in keys:
            if isinstance(value, dict):
                value = value.get(k)
            else:
                return default
        return value if value is not None else default
    
    def set(self, key, value):
        """设置配置项"""
        keys = key.split('.')
        config = self._config
        for k in keys[:-1]:
            config = config.setdefault(k, {})
        config[keys[-1]] = value
        self.save_config()

# 全局配置实例
```

5.4 摔倒检测算法模块实现

摔倒检测算法模块基于人体关键点进行摔倒判断，采用多维度融合算法，包括身体高宽比检测、躯干角度检测、头部位置检测、关键点分布检测四种方法。

核心实现代码（core/fall_detector.py）：

```python
import numpy as np
from collections import deque
from loguru import logger
from .detector import PoseEstimator

class FallDetector:
    """摔倒检测器"""
    
    def __init__(self):
        self.pose_estimator = PoseEstimator()
        self.angle_threshold = 45  # 躯干角度阈值
        self.height_ratio_threshold = 1.0  # 高宽比阈值
        self.confirm_frames = 5  # 连续帧确认数
        self.person_states = {}  # 状态追踪
    
    def detect(self, frame):
        """
        检测摔倒
        返回: [{'bbox': tuple, 'is_falling': bool, 'confidence': float, 'keypoints': array}, ...]
        """
        poses = self.pose_estimator.estimate(frame)
        results = []
        
        for pose in poses:
            bbox = pose['bbox']
            keypoints = pose['keypoints']
            
            # 多种摔倒判断方法
            fall_score = 0
            checks = 0
            
            # 方法1: 身体高宽比
            ratio_fall = self._check_height_ratio(bbox)
            if ratio_fall is not None:
                fall_score += ratio_fall
                checks += 1
            
            # 方法2: 躯干角度
            trunk_fall = self._check_trunk_angle(keypoints)
            if trunk_fall is not None:
                fall_score += trunk_fall
                checks += 1
            
            # 方法3: 头部位置
            head_fall = self._check_head_position(keypoints, bbox)
            if head_fall is not None:
                fall_score += head_fall
                checks += 1
            
            # 方法4: 关键点分布
            dist_fall = self._check_keypoint_distribution(keypoints)
            if dist_fall is not None:
                fall_score += dist_fall
                checks += 1
            
            # 综合判断
            is_falling = False
            confidence = 0
            if checks > 0:
                confidence = fall_score / checks
                is_falling = confidence > 0.5
            
            results.append({
                'bbox': bbox,
                'is_falling': is_falling,
                'confidence': confidence,
                'keypoints': keypoints
            })
        
        return results
    
    def _check_height_ratio(self, bbox):
        """检查身体高宽比"""
        x1, y1, x2, y2 = bbox
        width = x2 - x1
        height = y2 - y1
        
        if width == 0 or height < 100 or width < 50:
            return None
        
        ratio = height / width
        # 正常站立时高度>宽度，摔倒时宽度可能>高度
        if ratio < self.height_ratio_threshold:
            return 1.0
        return 0.0
    
    def _check_trunk_angle(self, keypoints):
        """检查躯干角度"""
        # 获取肩部和髋部中点
        left_shoulder = self._get_keypoint(keypoints, 5)
        right_shoulder = self._get_keypoint(keypoints, 6)
        left_hip = self._get_keypoint(keypoints, 11)
        right_hip = self._get_keypoint(keypoints, 12)
        
        if None in [left_shoulder, right_shoulder, left_hip, right_hip]:
            return None
        
        # 计算肩部和髋部中点
        shoulder_mid = ((left_shoulder[0] + right_shoulder[0]) / 2,
                       (left_shoulder[1] + right_shoulder[1]) / 2)
        hip_mid = ((left_hip[0] + right_hip[0]) / 2,
                  (left_hip[1] + right_hip[1]) / 2)
        
        # 计算躯干与垂直方向的角度
        dx = shoulder_mid[0] - hip_mid[0]
        dy = shoulder_mid[1] - hip_mid[1]
        angle = np.degrees(np.arctan2(abs(dx), abs(dy)))
        
        if angle > self.angle_threshold:
            return min(angle / 90, 1.0)
        return 0.0
    
    def _check_head_position(self, keypoints, bbox):
        """检查头部位置是否异常低"""
        nose = self._get_keypoint(keypoints, 0)
        left_hip = self._get_keypoint(keypoints, 11)
        right_hip = self._get_keypoint(keypoints, 12)
        
        if nose is None or (left_hip is None and right_hip is None):
            return None
        
        if left_hip and right_hip:
            hip_y = (left_hip[1] + right_hip[1]) / 2
        else:
            hip_y = (left_hip or right_hip)[1]
        
        # 头部低于髋部可能是摔倒
        if nose[1] > hip_y - 20:
            return 1.0
        return 0.0
    
    def _check_keypoint_distribution(self, keypoints):
        """检查关键点的水平分布"""
        valid_points = []
        for kpt in keypoints:
            if kpt[2] > 0.3:
                valid_points.append((kpt[0], kpt[1]))
        
        if len(valid_points) < 8:
            return None
        
        points = np.array(valid_points)
        x_range = np.max(points[:, 0]) - np.min(points[:, 0])
        y_range = np.max(points[:, 1]) - np.min(points[:, 1])
        
        if y_range == 0:
            return 1.0
        
        # 水平分布大于垂直分布时可能是躺倒
        ratio = x_range / y_range
        if ratio > 1.5:
            return min(ratio / 3, 1.0)
        return 0.0
    
    def _get_keypoint(self, keypoints, idx):
        """获取指定关键点"""
        if idx < len(keypoints) and keypoints[idx][2] > 0.3:
            return (keypoints[idx][0], keypoints[idx][1])
        return None
```

5.5 区域闯入检测模块实现

区域闯入检测模块负责检测区域的管理与闯入判断。支持多边形区域配置，使用OpenCV的pointPolygonTest函数判断点是否在区域内。

核心实现代码（core/intrusion_detector.py）：

```python
import cv2
import numpy as np
from loguru import logger
from .config_manager import config

class Zone:
    """检测区域"""
    
    def __init__(self, zone_id, name, points, color=[255, 0, 0]):
        self.id = zone_id
        self.name = name
        self.points = np.array(points, dtype=np.int32)
        self.color = tuple(color)
    
    def contains_point(self, point):
        """检查点是否在区域内"""
        result = cv2.pointPolygonTest(self.points, point, False)
        return result >= 0
    
    def contains_bbox(self, bbox, threshold=0.3):
        """检查边界框是否在区域内"""
        x1, y1, x2, y2 = bbox
        
        # 检查中心点
        center = ((x1 + x2) // 2, (y1 + y2) // 2)
        if self.contains_point(center):
            return True
        
        # 检查底部中心点（人的脚部位置）
        bottom_center = ((x1 + x2) // 2, y2)
        if self.contains_point(bottom_center):
            return True
        
        return False
    
    def draw(self, frame, alpha=0.3):
        """在画面上绘制区域"""
        overlay = frame.copy()
        cv2.fillPoly(overlay, [self.points], self.color)
        cv2.addWeighted(overlay, alpha, frame, 1 - alpha, 0, frame)
        cv2.polylines(frame, [self.points], True, self.color, 2)
        
        # 绘制区域名称
        x_min = int(np.min(self.points[:, 0]))
        y_min = int(np.min(self.points[:, 1]))
        cv2.putText(frame, f"Zone-{self.id}", (x_min + 10, y_min + 25), 
                   cv2.FONT_HERSHEY_SIMPLEX, 0.6, (255, 255, 255), 2)
        return frame


class IntrusionDetector:
    """区域闯入检测器"""
    
    def __init__(self):
        self.zones = []
        self.load_zones_from_config()
    
    def load_zones_from_config(self):
        """从配置加载区域"""
        zones_config = config.get('intrusion.zones', [])
        self.zones = []
        for z in zones_config:
            zone = Zone(
                zone_id=z['id'],
                name=z['name'],
                points=z['points'],
                color=z.get('color', [255, 0, 0])
            )
            self.zones.append(zone)
        logger.info(f"加载了 {len(self.zones)} 个检测区域")
    
    def detect(self, detections):
        """
        检测闯入
        detections: [(x1, y1, x2, y2, confidence), ...] 或 [{'bbox': tuple}, ...]
        返回: [{'zone': Zone, 'bbox': tuple, 'intrusion': bool}, ...]
        """
        results = []
        
        for det in detections:
            if isinstance(det, dict):
                bbox = det.get('bbox')
            else:
                bbox = det[:4]
            
            for zone in self.zones:
                is_intrusion = zone.contains_bbox(bbox)
                if is_intrusion:
                    results.append({
                        'zone': zone,
                        'zone_id': zone.id,
                        'zone_name': zone.name,
                        'bbox': bbox,
                        'intrusion': True
                    })
        
        return results
    
    def draw_zones(self, frame):
        """绘制所有区域"""
        for zone in self.zones:
            frame = zone.draw(frame)
        return frame
```


5.6 事件分析与预警模块实现

事件分析与预警模块负责异常事件的预警通知与记录管理。支持声音预警、邮件通知、Webhook推送三种预警方式，并提供冷却时间机制避免重复预警。

核心实现代码（core/alert_manager.py）：

```python
import time
import threading
import requests
import smtplib
from email.mime.text import MIMEText
from datetime import datetime
from collections import deque
from loguru import logger
from .config_manager import config
from .database import DatabaseManager

class Event:
    """事件类"""
    EVENT_FALL = "fall"
    EVENT_INTRUSION = "intrusion"
    
    def __init__(self, event_type, camera_id, details=None):
        self.id = None
        self.type = event_type
        self.camera_id = camera_id
        self.timestamp = datetime.now()
        self.details = details or {}
        self.handled = False
    
    def to_dict(self):
        return {
            'id': self.id,
            'type': self.type,
            'camera_id': self.camera_id,
            'timestamp': self.timestamp.isoformat(),
            'details': self.details,
            'handled': self.handled
        }


class AlertManager:
    """预警管理器"""
    
    def __init__(self):
        self.enabled = config.get('alert.enabled', True)
        self.cooldown = config.get('alert.cooldown', 30)
        self.methods = config.get('alert.methods', {})
        self.last_alert_time = {}
        self.db = DatabaseManager()
        self.callbacks = []
    
    def register_callback(self, callback):
        """注册事件回调"""
        self.callbacks.append(callback)
    
    def trigger_event(self, event):
        """触发事件"""
        if not self.enabled:
            return
        
        # 检查冷却时间
        event_key = f"{event.type}_{event.camera_id}"
        current_time = time.time()
        
        if event_key in self.last_alert_time:
            if current_time - self.last_alert_time[event_key] < self.cooldown:
                return
        
        self.last_alert_time[event_key] = current_time
        
        # 保存到数据库
        event.id = self.db.save_event(event)
        
        # 执行回调
        for callback in self.callbacks:
            try:
                callback(event)
            except Exception as e:
                logger.error(f"回调执行失败: {e}")
        
        # 发送预警
        self._send_alerts(event)
        logger.warning(f"触发事件: {event.type} - 摄像头{event.camera_id}")
    
    def _send_alerts(self, event):
        """发送预警通知"""
        # 声音预警
        if self.methods.get('sound', False):
            self._play_sound()
        
        # Webhook推送
        if self.methods.get('webhook', False):
            threading.Thread(target=self._send_webhook, args=(event,)).start()
        
        # 邮件通知
        if self.methods.get('email', False):
            threading.Thread(target=self._send_email, args=(event,)).start()
    
    def _play_sound(self):
        """播放预警声音"""
        try:
            import winsound
            winsound.Beep(1000, 500)
        except:
            print('\a')
    
    def _send_webhook(self, event):
        """发送Webhook通知"""
        webhook_url = config.get('alert.webhook_url')
        if not webhook_url:
            return
        
        try:
            payload = event.to_dict()
            response = requests.post(webhook_url, json=payload, timeout=10)
            if response.status_code == 200:
                logger.info("Webhook发送成功")
        except Exception as e:
            logger.error(f"Webhook发送失败: {e}")
    
    def _send_email(self, event):
        """发送邮件通知"""
        email_config = config.get('alert.email', {})
        smtp_server = email_config.get('smtp_server')
        sender = email_config.get('sender')
        password = email_config.get('password')
        receivers = email_config.get('receivers', [])
        
        if not all([smtp_server, sender, password, receivers]):
            return
        
        try:
            type_names = {'fall': '摔倒检测', 'intrusion': '区域闯入'}
            msg = MIMEText(f"""
预警通知
类型: {type_names.get(event.type, event.type)}
时间: {event.timestamp.strftime('%Y-%m-%d %H:%M:%S')}
摄像头: {event.camera_id}
            """, 'plain', 'utf-8')
            msg['Subject'] = "摔倒检测系统预警"
            msg['From'] = sender
            msg['To'] = ', '.join(receivers)
            
            with smtplib.SMTP(smtp_server, 587) as server:
                server.starttls()
                server.login(sender, password)
                server.sendmail(sender, receivers, msg.as_string())
            logger.info("邮件发送成功")
        except Exception as e:
            logger.error(f"邮件发送失败: {e}")
```

5.7 机器运维与监控模块实现

机器运维与监控模块负责系统资源监控与健康检查。使用psutil库采集CPU、内存、磁盘等系统指标，并提供阈值告警机制。

核心实现代码（core/monitor.py）：

```python
import psutil
import threading
import time
from datetime import datetime
from loguru import logger

class SystemMonitor:
    """系统监控器"""
    
    def __init__(self):
        self.running = False
        self.monitor_thread = None
        self.metrics_history = []
        self.max_history = 1000
        self.cpu_threshold = 90
        self.memory_threshold = 90
        self.alert_callback = None
    
    def start(self):
        """启动监控"""
        self.running = True
        self.monitor_thread = threading.Thread(target=self._monitor_loop, daemon=True)
        self.monitor_thread.start()
        logger.info("系统监控已启动")
    
    def stop(self):
        """停止监控"""
        self.running = False
        if self.monitor_thread:
            self.monitor_thread.join(timeout=2)
        logger.info("系统监控已停止")
    
    def _monitor_loop(self):
        """监控循环"""
        while self.running:
            metrics = self.get_system_metrics()
            self.metrics_history.append(metrics)
            
            if len(self.metrics_history) > self.max_history:
                self.metrics_history = self.metrics_history[-self.max_history:]
            
            self._check_thresholds(metrics)
            time.sleep(5)
    
    def get_system_metrics(self):
        """获取系统指标"""
        cpu_percent = psutil.cpu_percent(interval=1)
        memory = psutil.virtual_memory()
        disk = psutil.disk_usage('/')
        
        gpu_info = self._get_gpu_info()
        
        return {
            'timestamp': datetime.now().isoformat(),
            'cpu': {
                'percent': cpu_percent,
                'count': psutil.cpu_count()
            },
            'memory': {
                'total': memory.total,
                'available': memory.available,
                'percent': memory.percent,
                'used': memory.used
            },
            'disk': {
                'total': disk.total,
                'used': disk.used,
                'free': disk.free,
                'percent': disk.percent
            },
            'gpu': gpu_info
        }
    
    def _get_gpu_info(self):
        """获取GPU信息"""
        try:
            import torch
            if torch.cuda.is_available():
                return {
                    'available': True,
                    'name': torch.cuda.get_device_name(0),
                    'memory_total': torch.cuda.get_device_properties(0).total_memory
                }
        except:
            pass
        return {'available': False}
    
    def _check_thresholds(self, metrics):
        """检查阈值并触发告警"""
        alerts = []
        
        if metrics['cpu']['percent'] > self.cpu_threshold:
            alerts.append(f"CPU使用率过高: {metrics['cpu']['percent']}%")
        
        if metrics['memory']['percent'] > self.memory_threshold:
            alerts.append(f"内存使用率过高: {metrics['memory']['percent']}%")
        
        if alerts and self.alert_callback:
            for alert in alerts:
                logger.warning(alert)
                self.alert_callback(alert)


class ServiceHealth:
    """服务健康检查"""
    
    def __init__(self):
        self.services = {}
    
    def register_service(self, name, check_func):
        """注册服务健康检查函数"""
        self.services[name] = check_func
    
    def check_all(self):
        """检查所有服务"""
        results = {}
        for name, check_func in self.services.items():
            try:
                status = check_func()
                results[name] = {
                    'status': 'healthy' if status else 'unhealthy',
                    'checked_at': datetime.now().isoformat()
                }
            except Exception as e:
                results[name] = {
                    'status': 'error',
                    'error': str(e),
                    'checked_at': datetime.now().isoformat()
                }
        return results
```

可视化与存储模块负责数据存储与Web界面展示。使用SQLite数据库存储事件记录，HTML5+TailwindCSS+Chart.js构建Web界面。

数据库核心实现代码（core/database.py）：

```python
import sqlite3
import json
from datetime import datetime
from pathlib import Path
from loguru import logger

class DatabaseManager:
    """数据库管理器"""
    
    def __init__(self):
        self.db_path = Path('data/fall_detection.db')
        self.db_path.parent.mkdir(parents=True, exist_ok=True)
        self._init_database()
    
    def _init_database(self):
        """初始化数据库表"""
        conn = self._get_connection()
        cursor = conn.cursor()
        
        # 事件表
        cursor.execute('''
            CREATE TABLE IF NOT EXISTS events (
                id INTEGER PRIMARY KEY AUTOINCREMENT,
                type TEXT NOT NULL,
                camera_id INTEGER,
                timestamp DATETIME DEFAULT CURRENT_TIMESTAMP,
                details TEXT,
                handled INTEGER DEFAULT 0,
                snapshot_path TEXT
            )
        ''')
        
        # 统计数据表
        cursor.execute('''
            CREATE TABLE IF NOT EXISTS statistics (
                id INTEGER PRIMARY KEY AUTOINCREMENT,
                date DATE,
                camera_id INTEGER,
                fall_count INTEGER DEFAULT 0,
                intrusion_count INTEGER DEFAULT 0,
                total_detections INTEGER DEFAULT 0
            )
        ''')
        
        conn.commit()
        conn.close()
        logger.info("数据库初始化完成")
    
    def _get_connection(self):
        """获取数据库连接"""
        return sqlite3.connect(str(self.db_path))
    
    def save_event(self, event):
        """保存事件"""
        conn = self._get_connection()
        cursor = conn.cursor()
        
        cursor.execute('''
            INSERT INTO events (type, camera_id, timestamp, details, handled)
            VALUES (?, ?, ?, ?, ?)
        ''', (
            event.type,
            event.camera_id,
            event.timestamp.isoformat(),
            json.dumps(event.details),
            0
        ))
        
        event_id = cursor.lastrowid
        conn.commit()
        conn.close()
        return event_id
    
    def get_events(self, event_type=None, limit=100):
        """查询事件"""
        conn = self._get_connection()
        cursor = conn.cursor()
        
        query = "SELECT * FROM events WHERE 1=1"
        params = []
        
        if event_type:
            query += " AND type = ?"
            params.append(event_type)
        
        query += " ORDER BY timestamp DESC LIMIT ?"
        params.append(limit)
        
        cursor.execute(query, params)
        rows = cursor.fetchall()
        conn.close()
        
        events = []
        for row in rows:
            events.append({
                'id': row[0],
                'type': row[1],
                'camera_id': row[2],
                'timestamp': row[3],
                'details': json.loads(row[4]) if row[4] else {},
                'handled': bool(row[5])
            })
        
        return events
    
    def get_event_statistics(self):
        """获取事件统计"""
        conn = self._get_connection()
        cursor = conn.cursor()
        
        cursor.execute("SELECT date, fall_count, intrusion_count FROM statistics ORDER BY date DESC")
        rows = cursor.fetchall()
        conn.close()
        
        total_falls = sum(row[1] for row in rows)
        total_intrusions = sum(row[2] for row in rows)
        
        return {
            'total_falls': total_falls,
            'total_intrusions': total_intrusions,
            'daily': [{'date': row[0], 'fall_count': row[1], 'intrusion_count': row[2]} for row in rows]
        }
```

7 总结与展望

7.1 总结

本项目设计并实现了基于YOLO与YOLO-pose的摔倒检测与区域闯入系统，主要完成了以下工作：

1. 技术选型与架构设计：选择Python+Flask+SQLite技术栈，采用模块化设计，将系统划分为九大功能模块，各模块职责清晰、耦合度低。

2. 核心算法实现：基于YOLOv8-pose提取人体17个关键点，采用身体高宽比、躯干角度、头部位置、关键点分布四种方法融合判断摔倒状态；使用OpenCV的pointPolygonTest实现区域闯入检测。

3. 系统功能实现：完成了多目标检测与人体姿态估计、视频流处理与数据采集、系统配置与管理、摔倒检测算法、区域闯入检测、事件分析与预警、机器运维与监控、API服务与消息推送、可视化与存储九大模块的开发。

4. 部署与测试：提供一键安装脚本，降低部署难度；通过功能测试验证系统可用性。

系统能够实时检测摄像头画面中的人体摔倒与区域闯入事件，并通过声音、邮件、Webhook等方式发送预警通知，具有较强的实用价值。

7.2 展望

尽管本系统已实现核心功能并通过测试，但仍有进一步优化与拓展的空间，未来可从以下方向开展工作：

1. 算法优化：引入深度学习模型轻量化技术，适配边缘设备部署；融合多模态数据（如红外视频），提升低光照环境下的检测精度；采用迁移学习方法，增强模型泛化能力。

2. 功能拓展：新增多目标检测（如车辆、危险品）与行为分析（如徘徊、奔跑）功能；开发移动端APP，支持远程实时监控；集成视频回放与智能检索功能。

3. 系统集成：与物联网设备联动，实现监控摄像头、门禁、报警装置的协同控制；对接现有安防平台，打通数据壁垒。

4. 交互体验：优化前端界面的响应式设计，适配更多终端设备；增加用户权限管理功能。

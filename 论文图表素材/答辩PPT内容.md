## 第9页 - 摔倒检测算法

**四种融合判断方法**

| 方法 | 原理 | 判断条件 |
|-----|------|---------|
| 身体高宽比 | 站立时高>宽，躺倒时宽>高 | ratio < 1.0 |
| 躯干角度 | 计算肩部-髋部连线与垂直方向夹角 | angle > 45° |
| 头部位置 | 正常时头在髋部上方 | 头部低于髋部 |
| 关键点分布 | 分析关键点水平/垂直分布 | 水平分布 > 垂直分布 |

**综合置信度 = 各方法得分加权平均**
**置信度 > 0.5 → 判定为摔倒**

## 第10页 - 区域闯入检测

**检测原理**

1. 配置多边形检测区域（支持任意形状）
2. 使用OpenCV的pointPolygonTest函数
3. 检测人体中心点/底部点是否在区域内
4. 进入区域即触发闯入预警

**核心代码**
```python
# 判断点是否在多边形区域内
result = cv2.pointPolygonTest(zone_points, person_center, False)
if result >= 0:
    trigger_intrusion_alert()
```

**三种预警方式**

| 预警方式 | 说明 | 适用场景 |

| 🔗 Webhook | HTTP POST推送 | 对接第三方系统 |

**冷却机制**
- 同类事件30秒内不重复预警
- 避免频繁告警造成干扰

非功能需求 具体参数
系统稳定性 视频流无卡顿，长时间运行稳定，单模块故障不影响整体
系统实时性 预警响应时间≤1秒，视频帧处理延迟可控

字段名 数据类型 主键 非空 说明

details TEXT 否 否 事件详情（JSON格式）

字段名 数据类型 主键 非空 说明

message TEXT 否 否 日志消息内容
timestamp DATETIME 否 是 记录时间

字段名 数据类型 主键 非空 说明
